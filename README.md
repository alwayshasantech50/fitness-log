# Project name:: 
fitness-log


# Short description:: 
fitness-log is a workout website built with Next.js. You can browse exercises, read their details, add workouts to today's plan, and save workouts for later.


## Technologies Used

- Next.js
- JavaScript
- React
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- localStorage



## Features::

- Browse workouts in a responsive card grid.
- View each workout's equipment, difficulty, duration, calories, rating, and instructions.
- Add up to five workouts to Today's Plan.
- Save workouts for later in a separate Saved tab.
- See the total exercises, minutes, and calories in Today's Plan.
- Sort workouts by duration, calories, or rating.
- See loading animations while workout data is loading.
